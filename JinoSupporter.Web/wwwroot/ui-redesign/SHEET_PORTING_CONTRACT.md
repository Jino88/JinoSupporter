# 화면 이식 규칙 — SHEET

여러 세션이 서로 다른 화면을 동시에 이식한다. 결과가 한 벌로 보이려면 아래를
그대로 따라야 한다. 이 문서와 어긋나는 판단이 필요하면 하지 말고 보고하라.

기준 시안: `wwwroot/ui-redesign/sheet/daily-report.html` (+ `sheet/assets/sheet.css`)
셸은 이미 이식됐다: `Components/Layout/InstrumentLayout.razor`, `assets/instrument.css`

---

## 0. 이 앱이 무엇인가

미세스피커 공장의 품질 기록이다. 엔지니어가 "이번 주에 어느 모델이 나빠졌고
왜인지"를 보고 **그대로 캡쳐해 보고서에 붙인다.** 그래서 화면은 그 보고서처럼
생겨야 한다 — 흰 종이, 잉크 선, 기준선 위의 숫자.

표를 캡쳐해 공유하는 것이 실제 사용 방식이므로 **표는 엑셀 격자를 유지한다.**
일부만 잘라내도 표로 읽혀야 한다.

---

## 1. 색 — 토큰만 쓴다

하드코딩 hex를 토큰으로 바꾼다. 토큰은 `instrument.css`가 정의하고 있고 셸이
이미 쓰고 있다.

| 쓸 곳 | 토큰 | 값 |
|---|---|---|
| 종이(패널·카드 바탕) | `--panel` | `#ffffff` |
| 옅은 바탕(표 헤더, 인셋) | `--panel-2` | `#f5f6f9` |
| 더 옅은 바탕 | `--panel-3` | `#eceef2` |
| 바깥 배경 | `--plane` | `#e8eaee` |
| 가는 선 | `--line` | `#dde1e7` |
| 진한 선(구획) | `--line-2` | `#c6ccd5` |
| 본문 글자 | `--ink` | `#0f1319` |
| 보조 글자 | `--ink-2` | `#4a5461` |
| 흐린 글자 | `--ink-3` | `#7f8a98` |
| 기본 동작(버튼) | `--signal` | 잉크 |
| **악화·불량** | `--crit` | 스탬프 레드 |
| **개선·양호** | `--ok` | 스탬프 블루 |

**색의 의미는 넷뿐이다.**

- **빨강 = 규격을 벗어남 / 나빠짐** — `--crit`, `--crit-wash`
- **파랑 = 좋아짐 / 통과** — `--ok`, `--ok-wash`
- **앰버 = 보류·주의** — 글자는 `--warn-ink`, 테두리는 `--warn-line`,
  바탕은 `--warn-wash`, 막대나 점 같은 신호에만 `--warn`
- **잉크(먹색) = 동작(버튼·현재 위치)** — `--signal`

앰버는 처음에 세 의미만 정의했다가 나중에 추가했다. 이 앱에는 "대기 중",
"검토 필요" 같은 상태가 실제로 있고, 그것을 빨강으로 칠하면 규격 이탈과
구분되지 않는다. `--warn`(#fab219) 하나만 있던 시절에는 그 색으로 글자를 쓸 수
없어 디자인 시스템과 페이지가 각자 어두운 앰버를 하드코딩했다 — 팔레트에
항목이 빠져 있던 것이지 페이지가 잘못한 것이 아니었다.

초록은 쓰지 않는다. 파랑을 개선에 쓰는 것은 국내 검사 성적서 관행이고
적록색약에 안전하기 때문이다. **버튼에 파랑을 쓰지 마라** — 파랑이 두 가지를
뜻하게 되어 의미가 흐려진다.

인디고·보라·청록 같은 **네 번째 액센트를 새로 만들지 마라.**

작성 형태는 `var(--crit, #c8342a)` 처럼 **폴백을 함께** 둔다. Classic UI에는
토큰이 없어서 폴백이 필요하다.

## 2. 색에만 의존하지 않는다

좋아짐/나빠짐은 **부호(+/−)나 위치로 먼저 읽히고** 색은 보조여야 한다.
가능하면 시안의 기준선 편차 막대처럼 **방향을 위치로** 표현한다.

## 3. 형태

- **모서리**: `border-radius` 는 `2px`. 카드에 8px, 12px 같은 큰 라운드를 쓰지 마라.
- **그림자**: `box-shadow` 를 쓰지 마라. 면 구분은 1px 선으로 한다.
  예외는 화면 위에 뜨는 오버레이(모달·팝오버)뿐이다.
- **여백**: 조밀하게. 이 화면들은 정보 밀도가 높은 것이 정상이다.

## 4. 표 — 엑셀 격자를 유지한다

```css
border-collapse: collapse;
```
- 모든 셀에 `1px solid var(--line)` 테두리
- 헤더는 `var(--panel-2)` 밴드 + 아래쪽만 `var(--line-2)`
- 숫자 칸은 `text-align: right; font-variant-numeric: tabular-nums;`
- hover 로만 보이는 정보를 만들지 마라(캡쳐하면 사라진다)

## 5. 글꼴 — 웹폰트 금지

공장 인트라넷에서 외부 폰트 요청이 지연된다. `<link>` 로 폰트를 불러오지 마라.
`instrument.css` 의 `--sans`(Segoe UI + 맑은 고딕)와 `--mono`(Bahnschrift)만 쓴다.
숫자에는 `font-variant-numeric: tabular-nums` 를 붙인다.

## 6. 높이 — 뷰포트를 소유하지 마라

이 화면들은 셸 안에서 열린다. `100vh` 를 그대로 쓰면 셸 크롬 높이만큼 넘친다.
`var(--view-h)` 를 쓰거나 부모 기준 비율로 바꾼다.

```css
/* 나쁨 */ height: calc(100vh - 235px);
/* 좋음 */ height: calc(var(--view-h, 100vh) - 201px);
```
`min-height` 로 걸어둔 가독성 바닥값은 함부로 지우지 마라. 작은 화면에서
일부러 크게 두려는 의도일 수 있으니, 지운다면 이유를 적어라.

## 7. 페이지 `<style>` 은 다른 화면으로 샌다

Razor 의 `<style>` 은 공유 문서에 그대로 주입된다. 따라서

- **맨 element 셀렉터 금지** — `h1 { }`, `table { }`, `td { }` 는 앱 전체에 적용된다.
- **디자인 시스템 이름 재정의 금지** — `.btn`, `.panel`, `.card`, `.select`, `.num`,
  `.ok`, `.muted`, `.empty`, `.card-body`, `.card-header` 등을 페이지에서 다시
  정의하지 마라. 이미 그렇게 된 곳이 13개 페이지에 있다.
- 새 클래스는 그 화면 고유 접두사를 붙인다(`dr-`, `didb-`, `qr-` 처럼).

## 8. 건드리지 말 것

- **C# 문자열 안의 HTML/CSS** — 내보내기용 리포트나 엑셀을 조립하는 코드다.
  `"<style>", "body{...}"` 처럼 문자열로 이어 붙는 것은 화면 스타일이 아니다.
- **기능·동작** — 이번 작업은 외형만이다. 이벤트 핸들러, 쿼리, 상태 로직을
  바꾸지 마라.
- **`instrument.css` / `instrument.scoped.css` / `InstrumentLayout.razor`** — 셸은
  다른 세션이 관리한다. 여기 손대면 충돌한다.
- **`HANDOFF.md`** — 여러 세션이 동시에 append 하면 충돌한다.

## 9. 검증

1. 빌드: `dotnet build JinoSupporter.Web/JinoSupporter.Web.csproj` 를 하되
   `bin/Debug` 가 아니라 artifacts 경로를 지정한다(이중 하이픈 artifacts-path).
   오류 0, **신규 경고 0**.
2. 렌더 대조: scratchpad 에 독립 HTML 하네스를 만들어 실제 CSS 로드 순서
   (`wwwroot/bootstrap/bootstrap.min.css` → `wwwroot/app.css` →
   `wwwroot/ui-redesign/assets/instrument.scoped.css` → 페이지 `<style>`) 를
   재현하고, 네가 고친 화면의 실제 마크업을 넣어 **수정 전/후를 각각 렌더해
   비교**한다. headless Chrome 은
   `/c/Program Files/Google/Chrome/Application/chrome.exe`, `--headless --dump-dom`
   으로 계산 스타일을 뽑을 수 있다.
3. 그 화면 밖의 무관한 마크업이 영향을 받지 않는지도 같은 하네스에서 확인한다.
4. **서버를 기동하거나 종료하지 마라.** 사용자가 5050 에서 쓰고 있다.
