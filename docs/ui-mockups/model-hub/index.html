Model management — 4 directions

Left: model groups from CompanyGlossary (MODULE › MSM / SI-SM, SPEAKER › BRS / MSU, UNIT, TWS). Click a model to see 1. Model Info, 2. Dev Plan (Production Input plan), 3. Dev History, 4. Issues, 5. Reviews. Sample data only.

A · Tree + Tabs

Classic master–detail. One category at a time.
  • Tree left, model header with phase pill, tabs with counts
  • Dev Plan tab = phase gantt + the Production Input plan table (Plan / Actual / Gap)
  • Easiest to build; best when each category grows large

B · Dossier + Timeline

Everything about one model on one scrolling page.
  • Section nav (1–5) jumps inside the page
  • Dev / Issue / Review merged on one dated timeline with filter chips
  • Best for "what happened to this model" reviews and meetings

C · Portfolio Board + Drawer

Pick a group, see its models as cards; open one in a side drawer.
  • Cards show phase stepper, open issues, NG PPM, last review
  • Sort by phase / open issues / NG rate
  • Drawer holds the 5 categories as accordions

D · Group Matrix

All models × all categories in one table.
  • Rows = group tree (collapsible), columns = 1–5 categories summary
  • Click a cell to open that model + category on the right
  • Best for managers comparing many models at once
